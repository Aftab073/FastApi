<h1 align="center">Blog Project with FastAPI and User Authentication</h1>

Overview
<p>This project is a simple blog application built using FastAPI, a modern Python web framework. It demonstrates CRUD (Create, Read, Update, Delete) operations for blog posts and includes user authentication features.</p>

Features
<ul>
<li><strong>User Authentication</strong>: Users can register, login, and logout.</li>
<li><strong>CRUD Operations</strong>: Users can create, read, update, and delete blog posts.</li>
<li><strong>Authorization</strong>: Only authenticated users can create, update, and delete blog posts.</li>
</ul>

Technologies Used
<ul>
<li><strong>FastAPI</strong>: A modern Python web framework for building APIs.</li>
<li><strong>Python</strong>: The programming language used for the project.</li>
</ul>

Installation and Running
<ol>
<li><strong>Clone the repository</strong>: <code>git clone https://github.com/Aftab073/FastApi/ </code></li>
<li><strong>Install dependencies</strong>: <code>pip install -r requirements.txt</code></li>
<li><strong>Run the application</strong>: <code>uvicorn main:app --reload</code></li>
</ol>

API Endpoints
<p>The following API endpoints are available:</p>

<ul>
<li><strong>POST /register</strong>: Register a new user.</li>
<li><strong>POST /login</strong>: Login an existing user.</li>
<li><strong>GET /posts</strong>: Retrieve a list of all blog posts.</li>
<li><strong>POST /posts</strong>: Create a new blog post.</li>
<li><strong>GET /blog/{blog_id}</strong>: Retrieve a single blog post.</li>
<li><strong>PUT /blog/{blog_id}</strong>: Update a blog post.</li>
<li><strong>DELETE /blog/{blogt_id}</strong>: Delete a blog post.</li>
</ul>
